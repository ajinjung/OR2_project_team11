# KBO 원년 프로야구 10일 경기 일정 최적화

- 목적 : 총 이동거리를 줄이면서, 각 구단이 자기 위치상 불가피한 최소 이동거리(하한)보다 비슷한 비율만 더 이동하게 하는 것이다.

## 실행 방법

**Google Colab에서 실행**한다.

## 설정값

노트북의 "GA 1회 실행" 셀에서 바꿀 수 있다.

| 항목 | 값 |
|---|---|
| 집단 크기 `pop` | 120 |
| 세대 수 `gens` | 600 |
| 교차 확률 `pc` | 0.9 |
| 변이 확률 `pm` | 0.05 (변이 5종 각각) |
| 국소탐색 `ls` | 0 (순수 GA) |
| 시드 `seed` | 0 |

## 결과 요약

최종 설정으로 시드 5개를 실행한 결과, 4개가 같은 최선값에 도달했다.

| 지표 | 값 |
|---|---|
| 목적함수 F | 0.2413 |
| 총 이동거리 | 8,655 km (무작위 실행 가능 일정 평균 11,714 km 대비 −26.1%) |
| 하한 대비 비율의 표준편차 σ(ρ) | 0.060 (무작위 평균 0.187) |
| 하드 제약 위반 | 0건 |

## 알고리즘 요약

- **염색체**: 10일 × 3경기 대진표(경기 = (홈팀, 원정팀)). 하루가 6팀의 완전 매칭이라 "매일 1경기"가 구조적으로 보장된다.
- **제약 처리**: "모든 순서쌍 1회"는 연산자가 보존하고, "연속 홈/원정 3경기 이하"와 "같은 대진 이틀 연속 금지"는 Deb 규칙(위반 수 우선) + repair로 처리한다.
- **연산자**: 토너먼트 선택, 연속 5~7일 블록 교차(남은 경기는 백트래킹으로 재구성), 변이 5종, 엘리트 보존, 이민자 교체.
- **목적함수**: F = 0.8 × 총 이동거리 항 + 0.2 × σ(ρ) 항 (각 항은 "최선 = 0, 무작위 평균 = 1"로 정규화).
